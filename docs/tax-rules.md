# ภาษีร้านค้าออนไลน์ — ขอบเขตและกฎที่ใช้ใน v1.5.5

ตรวจแหล่งข้อมูล ณ 2 พฤศจิกายน 2569 ระบบนี้ประมาณการสำหรับบุคคลธรรมดาขายสินค้าที่ซื้อมาขายไป มาตรา 40(8) จากรายได้ร้านที่บันทึกไว้ รวมยอดโอนและ COD ไม่ใช่โปรแกรมยื่นภาษีที่ครอบคลุมเงินได้ทุกประเภท

## หลักเกณฑ์ที่ใช้

- [พระราชกฤษฎีกาฉบับที่ 11](https://www.rd.go.th/2375.html): ค่าใช้จ่ายเหมา 60% สำหรับกิจการซื้อมาขายไปที่เข้าเงื่อนไข หรือค่าใช้จ่ายจริงตามความจำเป็นและสมควร
- [คู่มือ ภ.ง.ด.94 ปี 2569](https://www.rd.go.th/fileadmin/tax_pdf/pit/2569/Ins94_160669.pdf): ค่าลดหย่อนส่วนตัว 30,000 บาทครึ่งปี บุตรปกติ 15,000 บาท และบุตรที่เข้าเงื่อนไขคนที่สองขึ้นไปเกิดตั้งแต่ 2561 เพิ่ม 30,000 บาท ส่วนประกันสุขภาพบิดามารดาไม่หารสองโดยอัตโนมัติ
- ประกันชีวิตและดอกเบี้ยบ้านธนาคารครึ่งปีแยกส่วนลดหย่อน 10,000 บาทแรกกับส่วนยกเว้นที่เหลือ ไม่ใช้เพดาน 50,000 บาทแบบเดิม กรณีประกันชีวิตคู่สมรสแยกยื่นและผู้ให้กู้ประเภทกองทุน มีเงื่อนไขแยกตามคู่มือ
- [คู่มือ ภ.ง.ด.90 ปี 2568](https://www.rd.go.th/fileadmin/tax_pdf/pit/2568/Ins90_241268.pdf): อัตราก้าวหน้า วิธี 0.5% และเครดิตภาษี รวมถึงลำดับการหักเงินบริจาค
- [สรุปลดหย่อนของกรมสรรพากร](https://www.rd.go.th/fileadmin/user_upload/lorkhor/newsbanner/2025/12/PR1161_11122568.pdf): กองทุนมีเพดานเฉพาะและเพดานรวม ไม่ใช่กรอกรวมทุกกองทุนแล้วตัดที่ 500,000 บาทอย่างเดียว
- [คำถามตอบ ก.ล.ต. เรื่อง Thai ESGX](https://www.sec.or.th/TH/Documents/Thai%20ESGX/QA-LTF-to-Thai%20ESGX-010468.pdf): เงินลงทุนใหม่ Thai ESGX ปี 2569 ใช้วงเงินเดียวกับ Thai ESG สิทธิจาก LTF สับเปลี่ยนเป็นอีกประเภทหนึ่ง
- [ประกันสังคมสำหรับผู้ประกันตน ม.33 โดยฝ่ายทรัพยากรมนุษย์ จุฬาฯ](https://www.hrm.chula.ac.th/th/home/social-security-fund): ปี 2569 ใช้ฐานสูงสุด 17,500 บาท เงินสมทบปกติ 875 บาท/เดือน ระบบแยกเพดาน ม.33/39/40 และใช้ยอดที่จ่ายจริงในช่วงของแบบ กรณีเปลี่ยนประเภทผู้ประกันตนระหว่างปีหรือจ่ายสมทบพิเศษต้องตรวจเพิ่ม
- [ประกาศ e-Donation](https://www.rd.go.th/fileadmin/user_upload/lorkhor/press_release/2025/08/e-Donation_v.2.pdf): ตรวจผู้รับ ช่วงเวลามาตรการ และหลักฐานก่อนใช้สิทธิ ปี 2569 มีเงื่อนไข e-Donation เพิ่มเติม
- [เกณฑ์จด VAT](https://www.rd.go.th/7061.html): รายรับที่อยู่ในบังคับเกิน 1.8 ล้านบาทต่อปี ต้องจดทะเบียนภายใน 30 วันนับแต่วันที่เกิน ไม่ใช้เปอร์เซ็นต์ที่ปัดเศษมาตัดสิน

## ข้อมูลที่ผู้ใช้ต้องตรวจ

1. รายได้ขายสินค้าต้องครบทุกช่องทาง และเป็นยอดก่อนหักค่าบริการขนส่ง/แพลตฟอร์ม วันรับพัสดุไม่ใช่วันรับเงิน COD
2. รายจ่ายเดิมยังไม่ถูกยืนยันสิทธิภาษีอัตโนมัติ เปิดแก้ไขรายจ่าย ยืนยันว่าเป็นรายจ่ายที่หักได้ และระบุเลขที่/ที่เก็บหลักฐานก่อนใช้โหมดตามจริง ต้องปรับต้นทุนสินค้า/สินค้าคงเหลือและสินทรัพย์ตามเกณฑ์ด้วย
3. ต้นทุนซักรีดประมาณการยังใช้ในการบริหารกำไรได้ แต่ไม่ถูกนำไปหักภาษีตามจริงอัตโนมัติ
4. ค่าลดหย่อนแยกตามปีและแบบ กรอกยอดจ่ายจริงของช่วงนั้น ตรวจบุตรไม่ซ้ำช่อง คุณสมบัติครอบครัว กรมธรรม์ เงินลงทุน และเงินบริจาค
5. ช่องเงินสะสมเกษียณประเภทอื่นรับเฉพาะยอดที่ตรวจเพดานเฉพาะประเภทแล้ว และยังถูกจำกัดรวมกับ RMF/SSF/บำนาญ
6. หากมีเงินเดือนหรือเงินได้อื่น คู่สมรสรวมยื่น สิทธิคนพิการ/อายุ 65 ปี มาตรการซื้อสินค้า หรือ LTF สับเปลี่ยน Thai ESGX ให้คำนวณเพิ่มเติมในแบบจริง ระบบไม่อ้างว่าผลนี้เป็นยอดยื่นครบทุกกรณี

รองรับปี 2566–2569 ตามกฎที่ระบุ ไม่คาดเดากฎของปีถัดไป ภ.ง.ด.90 ปี 2569 ยังแสดงสถานะประมาณการจากกฎที่ตรวจได้ เนื่องจากยังไม่ได้ตรวจคู่มือสิ้นปี 2569 ครบถ้วน ค่าลดหย่อนที่กรอกเป็นข้อมูลชั่วคราวในหน้าปัจจุบัน ไม่บันทึกลงฐานข้อมูล

คำนวณตัวเลขด้วยความละเอียดสตางค์ และให้ตรวจการแสดงผล/การปัดเศษกับแบบจริงก่อนยื่น รายการสรุปไม่ใช่หมายเลขช่อง e-Filing

## ตรวจสอบการแก้ไข

`npm test` รันทดสอบสูตรและเส้นทางข้อมูลด้วย Node test runner ไม่เชื่อมต่อ Firebase

กรณีทดสอบครอบคลุมค่าลดหย่อนครึ่งปี เพดานกองทุน ลำดับบริจาค เกณฑ์ VAT เครดิตภาษี วันขอบเขตปีไทย และการแยกข้อมูลปี/แบบ

ทดสอบหน้าภาษีแยกจากระบบจริงด้วย `node node_modules/vite/bin/vite.js --config tests/browser/vite.config.js` เปิด URL ที่คำสั่งแสดง fixture ใช้ข้อมูลจำลองทั้งหมด สลับ `window.taxFixture.failExpenses` และกดรีเฟรชเพื่อทดสอบกรณีโหลดล้มเหลว
