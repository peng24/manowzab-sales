# SalesPilot v1.5.5 — การแก้ไขจากผลตรวจ

## สิ่งที่แก้

- T1–T3: แยกสูตรภาษีขายสินค้าออนไลน์เป็น `taxUtils.js` แก้สิทธิครึ่งปี เพดานเฉพาะกองทุนและลำดับบริจาค เพิ่มการตรวจตัวเลขไม่ถูกต้อง
- T4: แยกรายจ่ายที่ยืนยันสิทธิและหลักฐานจากต้นทุนประมาณการ เพิ่มช่องยืนยันในหน้ารายจ่าย ข้อมูลเดิมไม่ถูกตีความว่ามีหลักฐานโดยอัตโนมัติ
- T5: เทียบ VAT ด้วยยอดจริงและแสดงกำหนด 30 วันจากวันที่รายรับสะสมเกินในข้อมูลระบบ
- T6: ระบุขอบเขตบุคคลธรรมดาซื้อมาขายไป แยกค่าลดหย่อนปี/แบบ เพิ่มประเภทประกันสังคม ลบคำอ้างถูกต้อง 100% และหมายเลขช่อง e-Filing ที่สร้างเอง แสดงแหล่งกฎและข้อจำกัดสิ้นปี 2569
- S1/S4: คำขอเก่าเขียนทับคำขอใหม่ไม่ได้ การล้าง store ยกเลิกสิทธิอัปเดตของคำขอเดิม หน้าภาษีใช้ snapshot ท้องถิ่นที่โหลดรายได้และรายจ่ายสำเร็จครบพร้อมกัน ไม่พึ่งตัวกรองร่วมของหน้าอื่น วันเริ่ม/สิ้นปี query ใช้เขตเวลาไทยทั้งสอง service
- S2: การรวมลูกค้าล็อกด้วย transaction และ lease เก็บต้นทางจนย้ายครบทุกรายการ ย้ายข้อมูลเป็นช่วงและอ่าน version รายการขายก่อนเขียน ปลดล็อกเฉพาะ owner ของงานเดิมเมื่อผิดพลาด ลองทำต่อไปปลายทางเดิมได้
- S3: COD ใช้รหัสรายการคงที่ตามขนส่ง/เลขออเดอร์ ตรวจทั้งเอกสารเก่าที่ใช้วันใน ID และรายการซ้ำในไฟล์ แสดงรายการซ้ำ/ขัดแย้งก่อนบันทึก ข้ามรายการเดิม ไม่เขียนทับยอดหรือจำนวนตัวที่ตรวจแล้ว และใช้ transaction ป้องกันนำเข้าพร้อมกัน
- S5: ยอดโอนและโปรไฟล์ลูกค้าบันทึกใน transaction เดียว มีรหัสคำขอคงที่ระหว่างลองบันทึกซ้ำ ตรวจการแก้ฟอร์มหลังคำขอเดิมสำเร็จ ปฏิเสธลูกค้าที่กำลังรวมบัญชีในการสร้าง/แก้ไข/นำเข้า
- โหลดหน้าและ ExcelJS เมื่อใช้จริง เพื่อลดขนาด JavaScript ที่ต้องโหลดตอนเปิดระบบ แยก Firebase เป็น chunk ต่างหาก
- แก้ข้อความ .xls ให้ตรงกับตัวอ่าน .xlsx และป้องกันยอดนำเข้าที่ไม่ใช่ตัวเลข เพิ่มการระบุว่า COD ใช้วันที่รับเงิน ไม่ใช่วันรับพัสดุ

## ขอบเขตที่ยังต้องตรวจในระบบจริง

ไม่ได้แก้ไขหรือลบรายการขาย/ลูกค้าในฐานข้อมูลจริง ไม่ได้ย้ายเอกสาร COD เดิมอัตโนมัติ รายการเดิมที่ซ้ำหลายเอกสารจะถูกแจ้งขัดแย้งให้ตรวจประวัติ ไม่ลบรายการทางการเงินเงียบ ๆ

ยังไม่มี Security Rules ของ production ให้ตรวจ จึงไม่ได้เปลี่ยนสิทธิ์ Firestore และไม่ได้ยืนยันความถูกต้องของ rules ที่ติดตั้งจริง ตัวทดสอบ transaction จำลอง failure/atomicity ไม่แทนการทดสอบ Rules/Emulator แบบครบระบบ

อ้างอิงกฎภาษีและวิธีใช้งาน: [tax-rules.md](../tax-rules.md)
